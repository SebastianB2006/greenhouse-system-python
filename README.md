# greenhouse-system-python
Proiectul implementeaza in python un sistem pentru monitorizarea si gestionarea parametrilor de mediu (temperatura, umiditatea, ventilatia).

Cel mai greu lucru a fost că valorile și echipamentele erau scrise direct în cod și trebuia să modific manual fișierul de fiecare dată când voiam să schimb ceva.

Dacă aș reface proiectul, aș implementa un meniu interactiv în consolă pentru adăugarea dinamică a echipamentelor de la tastatură sau chiar o interfață grafică completă.
